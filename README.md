# Empty Threats? Conditionality Enforcement in Budget Support

Code and data for a master's thesis in Computational Social Science, UC3M.

The study asks whether donors enforce the conditions attached to general budget
support. The unit of observation is the activity-year: one budget support
operation in one year. Enforcement is measured as an interruption — an
activity-year in which the operation was live, money was still owed, and nothing
was disbursed.

Three hypotheses are tested. H1 asks whether a donor's structural position in a
recipient's budget support pool predicts interruption better than whether the
donor is bilateral or multilateral. H2 and H3 ask in which direction that
structural position operates, once donor and recipient differences are absorbed.

## How the pipeline is organised

```
extraction/     32 GB IATI source  ->  raw CSVs              cannot run on a clone
construction/   raw CSVs           ->  one row per activity   runs on any clone
analysis/       built dataset      ->  results                runs on any clone
```

Each stage reads only what the previous one wrote to `data/`. Nothing after
`extraction/` opens the source database.

## Running it

Open the folder in RStudio and render the documents in numerical order within
each stage. Start at `construction/`: everything it needs is already committed.

Packages used: tidyverse, DBI, RSQLite, httr2, lme4, broom.mixed, mice, glmnet,
ranger, gbm, rpart, rpart.plot, pROC, igraph, patchwork, scales, kableExtra,
DataExplorer, conflicted. One is off CRAN — `vdemdata`, installed from GitHub by
the script that uses it, and only needed to rebuild the political controls,
which are already committed.

### Why extraction cannot be reproduced by cloning

The source is [IATI Tables](https://tables.iatistandard.org/), a relational
rendering of the whole IATI Registry, refreshed daily and around 32 GB as
SQLite. It exceeds GitHub's 100 MB file limit by a factor of 300, so it is not
included here.


To rebuild that stage, download the current dump, place it where the setup chunk
of `extraction/01_frame.qmd` expects it, and render that document followed by
the harvest. If a render fails with `database is locked`, another program is
holding the file open — close any other R session or database client and try
again.

Nobody else needs to do this. Both scripts already ran, and their output is the
set of CSVs in `data/interim/`, which is committed.

## What each document does

**extraction/** — `01_frame` identifies every general or sector budget support
activity in the IATI corpus by aid modality rather than purpose code, and
exports the raw fields the next stage needs. It is the only script that touches
the 32 GB source. `02_harvest` downloads the programme documents behind the IATI
document links; it is resumable and manifest-tracked, and kept at `eval: false`
because a full run downloads for hours. `_harvest_functions.R` is the library it
sources.

**construction/** — `01_build_tables` assembles the raw CSVs into one row per
activity plus the activity-year panel, with the commitment-disbursement gap and
early-closure days computed. `02_external_controls` pulls recipient-country
governance, aid dependence and GDP per capita from the World Bank API.
`03_political_controls` adds coups and election timing from V-Dem.
`04_structural` builds S1 (the donor's share of the recipient's budget support),
S2 (fragmentation of the pool) and S3 (pool size).

**analysis/** — `01_eda_raw` diagnoses every variable before anything is cleaned
and chooses the enforcement measure against criteria fixed in advance; it names
problems rather than correcting them. `02_feature_engineering` applies those
corrections and assembles the panel the models estimate on. `03_network` builds
the donor-recipient bipartite structure and tests whether interruptions cluster.
`04_eda_clean` describes the analytical sample and produces the figures for the
data chapter. `05_models` estimates H2 and H3 with multilevel logistic
regression, built one level at a time. `06_prediction` tests H1 with repeated
grouped cross-validation, reporting the paired difference across 25 resamples
rather than two point estimates on a single split.

## Data

`data/interim/` holds the output of the extraction stage, and `data/external/`
the cached World Bank and V-Dem pulls. Both are committed: they are small,
human-readable, and they are what makes the rest of the pipeline reproducible.
`data/processed/` holds the built analytical datasets; the fitted model objects
are `.rds` and are regenerated by rendering rather than stored.

`data/raw/` is not in the repository. It is 13 GB — the IATI source database and
the harvested PDF corpus. The documents can be recovered from
`data/interim/document_manifest.csv`, which carries the URL and SHA1 of each
one.
